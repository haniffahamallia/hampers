# Niffalla Luxury Hampers

Landing page + order database (Google Sheets + Apps Script).

**API sudah di-set.** Baca `SETUP.md` untuk langkah yang harus dilakukan.

## Deploy ke GitHub Pages

Upload file-file ini ke **root** repo:
- `index.html`
- `script.js`
- `style.css`
- `CNAME`
- `site.webmanifest`
- `favicon*`
- `assets/`

Jangan upload folder `orphan/` dan `apps-script/` ke GitHub Pages (tidak dibutuhkan untuk website).

# Niffalla Luxury Hampers

Landing page + sistem order database (Google Sheets).

## Setup

Baca file **SETUP.md** di folder induk (`niffalla-order-system/SETUP.md`).

Langkah singkat:
1. Buat Google Sheet + pasang Apps Script (`apps-script/Code.gs`)
2. Deploy Web App → copy URL
3. Ganti `APPS_SCRIPT_URL` di `script.js`
4. Push folder ini ke GitHub Pages

## Fitur

- Keranjang belanja
- Form data pemesan (nama, WA, catatan)
- Order otomatis tercatat ke Google Sheet
- Checkout via WhatsApp (dengan Order ID)
